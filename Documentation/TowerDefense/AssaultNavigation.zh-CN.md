# 塔防地面单位的移动和接战

林间哨站的旧版在道路无回压时能走完全程，但在基地前排满、再腾出位置时，仍可能堵在弯道。截图也显示了另一类现象。基地外已经形成第一圈，后队却沿路堆积，截图右上的单位还在接战区边缘滞留。单帧只能定位现象，无法判定当时的站位可达性。验证时必须分开测道路、接战区、实际攻击和画面。

| 问题 | 需要分别处理的情况 |
| --- | --- |
| 路线与地形 | 玩家应能预判敌人走哪条路。小怪与重甲按各自半径通过路段、弯道和桥口。道路进度应单调，防止跳过弯道抄近路。水面、岩石、塔和基地有独立的通行边界。 |
| 群体交通 | 混速前后车、入口背压、直角转弯、窄口汇流、塔占地和单位死亡。领先单位获得通行优先权，后方单位可等待，但空位出现后队首应继续。 |
| 接战与围攻 | 进入基地近区、选可达合法攻击位、保留进场通路、移动到位、外圈候补、释放和补位。满员才形成队列，不能因为预约失败就把近区当成墙。 |
| 攻击与表现 | 身体与基地外沿的距离、攻击前摇与间隔、空位出现的时间。等待者不能远距离扣血。视图要和逻辑位置、行进方向与攻击事件一致。 |
| 地图制作 | 逻辑图要能叠加在底图上检查。实际地形容量不足时，先验证几何，再用已通过的通行图指导绘制底图。逻辑导航的网格和美术贴图上的装饰格子各自可以有不同的分辨率。 |

## 实现边界

1. 先备份旧域逻辑、RVO2 组件及配置。切断 RVO2 运行和编译引用。用生产路线、地形和塔的碰撞边界验证新算法，地图和半径保留作为对照。
2. 主路依照路线弧长推进。同一路线前车先推进，后车只移动到实际净空允许的位置。每段位移都检测扫掠碰撞。进接战区由局部调度接管，路上的单位不能占用已预留的进入通路。
3. 基地近区按体型缓存静态通行网格和多入口距离场。候选点要同时满足地形、占位、攻击距离和连续路径。队首可先占面前空位，后续优先填能走到的远侧空间，再安排合法候补位置。站位与路径一起预留，单位离开、死亡或走完对应路段后释放。攻击仍通过战斗域的前摇、间隔与扣血规则结算。
4. 地图没有通行区域与基地足迹数据时，继续支持其已有的编排路线和攻击路径。传送门目标保留独立离场逻辑。路线、形状或容量有问题时先输出地形诊断，再决定是否由关卡配置解决。

## 验收

- 纯道路用稀疏与满队列分别跑。记录是否全部通过，是否越路、穿墙、重叠或在前方已空时停住。
- 无塔攻城先让队列自然饱和。记录正面、两翼、后侧可达面积、攻击人数、候补数和停在道路上的数量。物理满员时保留可解释的排队。
- 分别释放单个攻击位、连续释放不同位置、周期性清空前圈。记录首次攻击、补位耗时、单只单位是否实际命中、以及前圈空着但场上仍有敌人的时间。把彻底断流和有限等待分开。
- 使用多种形状，包括窄桥、急弯、封一翼、双入口、混合体型和真实林间哨站。多种固定种子运行，输出实际场景图像。通过业务模拟后再编译窗口版，在真实渲染下观察一段连续进场与围攻。

## 本轮结果

在原图、旋转 180° 的内存测试图和重甲提前出场的变体中，无塔持续释放攻击位后，126 只敌人均实际命中基地。林间哨站的 25 次单点腾位也都有新的敌人命中。狭桥、单侧封堵、双入口、合流和塔占地分别用独立地形验证。完全封住的桥没有可通过路径，工具会记录对应路段与半径。

真实 Unity Game View 用同一套业务和美术跑了两种耐久。耐久 20 的诊断副本第 527 tick 正常败北。耐久 100000 的压力场景第 1700 tick 有 9 只持续攻击、63 只已刷出，后队因实体空间不足排到入口。南侧三个相邻空格最多能容纳一只普通怪，但从候补位置没有连续净空足够的路线。压力场景先后释放正面和背面的站位，新的敌人分别在 1.30 秒和 2.75 秒后实际命中。

配置地图时先检查最宽敌人的通行胶囊、各入口与接战区的连通性，以及攻击区能容纳多少实体。地形确实切断通路或容量低于关卡目标时，先在可验证的逻辑图上调整入口、桥宽或基地近区，再对齐底图。诊断方法与回放命令见 [导航验证说明](../../Verification~/NavigationScenarios/README.md)。

## 攻击范围外的包围

候补位置与攻击位置分开分配。候补允许在自己的攻击范围之外靠近基地，仍按实际体型与单位保持净空。先用进场距离场选择更深的可达外圈位置，等进场者走过侧翼通路，再安排下一只候补。中心入口留作通行，有可达攻击位时先安排攻击。

林间哨站的无塔压力模拟中，外圈候补从西侧 3 只增到 18 只，分布在西、北、东三侧。攻击者同时有 11 只。单点腾位的 25 次试验中，22 次在 9 秒内补位命中，已确认能直达的 10 次全部补位。清空前排后，仍有 126/126 只逐一命中基地。稳定包围的验收分开计数攻击者、实际到位的候补、进场中和在道路等候的单位。
