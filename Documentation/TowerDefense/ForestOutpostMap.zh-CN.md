# 林间哨站地图数据

`Assets/GameAssets/TowerDefense/Maps/ForestOutpostGrid.bytes` 是地图的编辑源。地图宽 44 格、高 30 格，每格 500 毫米。世界原点取西南边界 `(-11000, -7560)`，数据行从北向南保存。

`Assets/GameAssets/TowerDefense/Art/Map.png` 是对应的 2D 贴图。`Map.json` 保存关卡使用的道路折线、炮塔落位范围和贴图对位参数。位置以格子数据为准，贴图以 55° 俯角呈现。

| 标记 | 地形 |
| --- | --- |
| `.`、`S` | 主路、入口 |
| `+`、`a` | 基地周围的开阔草地 |
| `B` | 基地占地 |
| `#` | 草地或边界 |
| `~`、`^`、`*` | 水面、高地、实体树石 |

坐标从零开始。木桥覆盖第 17 至 20 列、第 13 至 14 行。左侧树石带接到上池，右侧崖脊接到下池。基地中心在世界坐标 `(8350, -4560)`，模型由游戏摆放。地图改版时，同步更新贴图、编辑源和 `Map.json`。
