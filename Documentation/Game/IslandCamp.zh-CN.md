# 海岛营地大厅

游戏从 `Assets/Scenes/Bootstrap.unity` 启动。首次抵达营地后进入《潮汐之灯》主线，玩家从营地出征、守住防线，再返营推进剧情。营地场景由 `CampSceneView` 在运行时创建。

## 世界尺度与营地区域

潮汐营地是大海岛上一处靠海的落脚点。木船停在前景浅湾，溪水从右侧落下汇入海湾。左侧草地是生活区，右侧留给农田和畜舍。上方林道通向画外，营地画幅只描述岛上的这一处落脚点。默认镜头按窗口宽高比等比容纳整张底图，拉近时底图和建筑一起移动。

当前仍只实现营地、建设、任务和塔防往返。探索系统与全岛小地图暂不开发，先在构图和模块边界上保留扩展可能。

## 首版玩法

营地设施按剧情和战果自动落在预设位置。「整备营地」是一次确认，确认后直接摆好工作台和围栏。玩家在塔防战场仍然亲自选塔、选建造点和升级。

### 固定建筑位

以底图左上为 `(0, 0)`、右下为 `(1, 1)`，用建筑与地面接触处的中心作为落点。运行时根据固定的相机俯角把落点换算到营地地面。正式模型还要核对占地、朝向、入口和交互范围。

| 设施 | 底图落点 `(U, V)` | 出现条件或用途 |
| --- | --- | --- |
| 帐篷 / 小屋 | `(.278, .509)` | 抵达后出现帐篷，累计第二次胜利在同一位置换成小屋 |
| 篝火 | `(.285, .615)` | 抵达后出现，位于帐篷前面 |
| 补给箱 | `(.161, .664)` | 抵达后出现，位于左侧生活区的前角 |
| 工作台 | `(.396, .515)` | 确认整备后出现在帐篷右边 |
| 围栏与庭院 | `(.293, .567)` | 围栏在整备时出现，庭院铺地随营地升级出现 |
| 农田 | `(.646, .582)` | 首胜返营后出现在右侧草地 |
| 取水点 | `(.613, .675)` | 随农田出现，位于田前，点击范围跟随取水点模型 |
| 任务牌 | 约 `(.398, .659)` | 预留在生活区与中间通道之间 |
| 羊栏 | 约 `(.586, .431)` | 预留在农田后方 |
| 鸡舍 | 约 `(.727, .445)` | 预留在羊栏右侧、溪流左侧 |

### 剧情与首次出征

| 节点 | 画面与叙事 | 业务触发 |
| --- | --- | --- |
| 潮汐之后 | 风暴后的木船搁在浅滩。漂流者把能用的帆布和木箱搬到草地，天黑前点起篝火。 | 序章完成或主动跳过后，保存抵达状态并出现帐篷、篝火和补给箱。失败或取消保留重试入口。 |
| 林间信号 | 林道深处传来三短一长的钟声。阿澜困在桥对岸，需要玩家掩护她剪断铃绳。 | 整备后自动布置工作台和围栏。出征前选择箭具箱或修理工具。 |
| 守住路口 | 准备页显示敌人、路线和补给。首战提示观察内弯和防御塔射程。 | 进入战场后有 10 秒备战时间。玩家可以建塔、等待敌人进攻，或点「立即开战」。 |
| 把补给带回来 | 守住哨站后，带回种子和取水工具。右侧草地出现田垄和取水点。 | 首次胜利随战报一次性提交农田与取水点的解锁。失败可重试或返营。累计第二次胜利时自动换成小屋。 |

营地档案按抵达状态和营地等级恢复设施。首次通关当前主线关卡时，章节进度和战报补给一起保存。旧存档以原营地等级为下限，有哨站胜利的档案从首胜返营接续。

### 后续章节

| 关卡 | 剧情触发与防守内容 |
| --- | --- |
| 瀑布水闸 | 首胜返营选择干粮或清水，查看取水点后出征。前两波走河岸，第三波起改走石桥。胜利后带回灯塔传动轮。 |
| 山脊接力站 | 玩家决定集中守主站或点亮副站。石阶和林道同时来敌。点亮后守住副站，可以在灯塔战提前看到每波的入口。 |
| 白崖灯塔 | 掩护阿澜修灯，挡住两路敌人与潮甲巨像。胜利后依次敲两声慢钟，再打开回潮闸。 |
| 天亮以后 | 选择留岛值守或送航图回港。尾声后可在营地重访四个战场。 |

三张后续战场使用 2D 底图和 3D 占位模型。Luban 配置关卡、出怪、路线和可落塔的坐标，营地对白与波间提示来自 `Camp/Story/TideCampaign`。

林间哨站首胜后，下次打开出征准备页即可在第二排选择池畔阶地、峡谷双潭、瀑布环岭和双路合流。每张支线战场有六波敌人，按营地当前等级结算战后补给。瀑布环岭的基地设在中央高台，敌人经右侧石阶到达。

### 首关塔防内容

林间哨站有 240 局内金币、20 点基地生命、1 条路线和 6 波敌人。选塔后用鼠标位置的绿红预览区分可建与不可建。首波在倒计时结束后自动开始。后续波次由玩家点击「开始本波」。

- **橡木箭塔 · 60 金币**。开局便宜、射程最长，适合放在内弯兼顾前后路段。
- **星光法塔 · 90 金币**。单发伤害高，适合布置在能持续攻击高生命敌人的塔位。
- **速射炮塔 · 75 金币**。攻击频率高、射程较短，适合在快速敌人集中经过的路段连续输出。三塔沿用现有单体即时命中规则。

| 波次 | 沿用的敌人配置 | 本波让玩家理解什么 |
| --- | --- | --- |
| 1 试探 | 8 苔团 | 看懂敌人路线、塔的射程和基地掉血。清波后首次三选一。 |
| 2 快袭 | 12 苔团、4 疾风团 | 利用覆盖更长的路段与高攻速处理快速敌人。 |
| 3 重压 | 6 石甲团、12 苔团 | 认识高生命敌人，考虑加塔、升级或采用高单发伤害。 |
| 4 追击 | 20 疾风团、5 石甲团 | 检查后段补防，给快速敌人和后续重敌留好输出。 |
| 5 混编 | 12 石甲团、18 疾风团 | 把前几波的选卡收益转成塔群配合，为最终波做准备。 |
| 6 守住哨站 | 1 蘑菇领主、20 苔团、8 石甲团 | 首领与随后的敌群都要处理。守完最后一个敌人后结算胜利，返营解锁首胜设施。 |

第 1–5 波后沿用清波金币和三选一。卡牌先保留伤害、攻速、射程、金币和基地修复，选完回到备战。首版继续用现有 Luban 的关卡、塔、怪、波次和刷怪组。建筑落点集中在营地表现层，剧情继续用 Story 资源，正式服务器只需接收业务状态和稳定 ID。

## 手记、档案与出征准备

营地 HUD 左上显示旅人，右上集中显示木材、石料和海岛手记。左下展示营地阶段，右下按剧情显示整备、哨站消息或出征入口。提示集中在短时浮条中。剧情对白贴近左下，给中央营地与近岸留出空间。

抵达后可在右侧镜头面板拉近、拉远或复位。镜头保持 55° 俯角，以营地为中心平滑缩放。营地原画是平面底图，等比覆盖窗口并对齐建筑落点。树木、小船和瀑布由底图表现。

首次完成或跳过抵达序章后，营地头像下方出现「设定旅人」提示。玩家可以预览并选择林地、海岸或营火外貌，同时设置昵称，也可以点「稍后再说」直接继续。以后从左上角头像打开旅人档案，点击「编辑资料」即可更改。档案也展示探索经验、战绩、累计建塔/强化次数和自动结算经验的旅程目标。

点击营地可查看当前状态和下一步提示。任务按钮打开海岛手记，显示目标、进度、材料与探索经验。完成的任务可领取一次。出征按钮先打开准备页，显示实际关卡的波数、敌人、路线、塔位、初始金币、基地耐久、塔型费用和胜负补给。确认后才加载战场，取消则留在营地。新出征生成种子，准备失败重试或局内重开沿用本次种子。返回时刷新材料、战绩、任务和建筑外观。

木石来自任务与已结束的塔防。胜负补给由出征时的 CampLevel 配置决定，完整结算后记入本地档案。

## 模块与所有权

| 模块 | 职责 |
| --- | --- |
| ClientFlow | 营地与塔防往返、资源生命周期、剧情播放和战报重试 |
| JourneyProgress | 在同一次保存中提交战绩、旅程目标、营地补给和设施里程碑 |

| PlayerHubView | 大厅 HUD、整备和任务按钮、下一步提示 |
| PlayerProfileView / TravelerIdentityView | 玩家成长、统计与旅程目标展示，昵称与外貌的预览、保存和取消 |
| ExpeditionPlan / ExpeditionView | 锁定本次关卡与种子，展示实际配置与波次情报，确认/取消/失败重试 |
| CampSceneView | 营地 2D 底图、四级 3D 建筑表现、场景选择、相机与光照 |

| CampArrivalView | SDK StoryPlayer 的 TMP 呈现器，播放抵达序章和哨站对白 |

GameEntry 的初始化顺序不增加营地业务；HotGame 仍装配通用系统后调用 ClientFlow。没有新增全局营地单例或第二套窗口框架。

## 数据、剧情与资源

当前共 14 张 Luban 表。营地使用 CampLevel 的累计胜利门槛与补给，以及 CampTask 的目标与奖励。建筑位置定义在营地表现层。ClientTheme 配置海岛地图地址。

`Assets/GameAssets/Camp/Art/Island.png` 是潮汐营地局部底图，YooAsset 地址 `Camp/Art/Island`、标签 maps。抵达序章 `Camp/Story/Arrival` 和哨站消息 `Camp/Story/Outpost` 都是标签为 story 的 JSON 资源。`Tools~/build-camp-hud.py` 生成 `Common/UI/CampHud` 的九宫格面板、圆角进度条、按钮和图标。营地沿用战斗 HUD 的中粗与粗字重。

剧情使用 SDK StoryPlayer 与项目的 TMP 呈现器。完成对白或主动跳过后保存对应状态。剧情或保存失败后，可在大厅重试同一段。抵达补给在手记中单独领取。

业务档案继续使用 version 2。version 1 旧档保留昵称、战绩、经验和任务，并显式创建初始营地。营地字段升级为 format 2，读取 format 1 时把已完成抵达且已建围栏的营地视为已听过哨站对白，并按累计胜利补齐设施。不支持的格式保留原文件并报错。

整备、任务、旅人资料和战报都在完整档案保存成功后才替换当前状态。外貌预设以稳定编号保存在本地档案中，旧档自动显示林地外貌。胜负补给锁定出征时的营地等级，重试保存沿用该等级。保存失败后的待处理战报只在本次客户端运行期间保留。

## 战斗情报与暂停

准备页与局内情报共用 BattleBriefing，从实际刷怪组汇总每种敌人的数量；最后一波不承诺额外选卡。备战时预告下一波，防守中显示当前进攻和清波奖励；不另维护一份可能过时的波次文案。

BattlePauseState 分别保留手动暂停、应用挂起、失焦与返回确认。重复点击返回不会覆盖原暂停，关闭确认框只解除这一来源；系统回调也不能清除手动暂停。恢复焦点/前台后不补算后台时间，首个恢复帧不推进模拟。局内重开重置手动状态，保留尚未解除的系统挂起。选卡继续停止战斗 tick。

## 美术与后续内容

海岛底图、现有面板/头像/图标为生成资源；帐篷、围栏、庭院、水井与小屋当前仅为 Cube/简单几何体占位，用于检查位置、尺寸和建设状态，不继续精修 3D。用户通过 Meshy 提供正式模型、材质和 LOD，交付要求见[制作清单](MeshyBrief.zh-CN.md)；替换由表现层和资源映射处理。后续可增加玩家角色驻留、采集点、更多设施、角色任务和海岛章节，不把模拟经营系统一次塞进大厅入口。

卡牌基础显示已接通表中的 rarity/iconIndex，使用白/绿/蓝/紫/橙品级名称和颜色；抽取仍为原有单池权重。飞入、粒子等演出继续按[卡牌规划](CardDraft.zh-CN.md)后续制作。

[交付记录](../TowerDefense/Delivery.zh-CN.md)中的营地截图来自上一版底图。新底图使用原始设计图，尚未重拍运行画面。真机性能、正式服务器结算和 IL2CPP 各有独立验收范围。SDK 升级及热更程序集引用变化需要重建匹配的主包基线。
