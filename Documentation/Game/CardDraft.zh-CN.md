# 肉鸽卡牌等级、主题与选卡表现

本轮不制作飞入动画、粒子、Shader 或音效。基础卡面已接通 Luban rarity/iconIndex，显示品级名称、强调色和对应图标；抽取仍使用单池权重。下文中的分级抽取、流派主题资源和高品质演出是后续规划。

## 稀有度与卡牌成长

先采用魔兽世界式的五档辨识，卡面文字保持暖白/浅色；品级主要作用于边框、徽记和强调线，保证森林界面上的可读性。

| ID | 品级 | 主强调色 | 除颜色以外的识别 |
| --- | --- | --- | --- |
| 1 | 普通 | 象牙白 `#E8E4D8` | 一阶徽记、普通字样、素框 |
| 2 | 优秀 | 翠绿 `#1EFF00` | 二阶徽记、优秀字样、叶纹边饰 |
| 3 | 稀有 | 蓝色 `#0070DD` | 三阶徽记、稀有字样、晶石角饰 |
| 4 | 史诗 | 紫色 `#A335EE` | 四阶徽记、史诗字样、完整雕饰 |
| 5 | 传说 | 橙色 `#FF8000` | 五阶徽记、传说字样、专属冠饰 |

以上颜色用于小面积强调，可按实际画面对亮度调整；不做整卡高饱和纯色铺底。不把“稀有度”“同一卡的叠层”“塔的升级等级”混成同一字段。卡牌的当前叠层、最大叠层和选择后的收益独立显示，高稀有度优先提供改变构筑的机制，而不是无限放大所有数值。

## 主题与配色

主题表示流派，稀有度表示品级。以主题图案、图标和小面积副色区分，主边框仍遵循品级色，避免玩家分不清紫色代表法术还是史诗。

| 主题 | 副色/图形 | 设计方向 |
| --- | --- | --- |
| 林地/守护 | 苔绿、叶与盾 | 基地续航、耐久与防守 |
| 钢铁/射击 | 钢青、弩与齿轮 | 射速、投射物与精准 |
| 奥术/星辉 | 靛青、星环与晶体 | 法塔、技能与触发组合 |
| 烈焰 | 暗红铜色、火焰 | 范围/持续伤害流派，规则尚待实现 |
| 冰霜 | 冰青、雪晶 | 减速/控制流派，规则尚待实现 |
| 财富 | 铜金、钱币 | 局内经济与风险收益 |

森林与奥术可先覆盖现有图标，其他主题在有规则和内容后再扩展。卡面图标表达具体效果，不能仅给旧卡换颜色就声称新增了一套玩法。

## 配置粒度

Card 保留稳定 ID、名称/描述 key、rarity、theme、最大叠层、效果列表与图标；Card 的单行描述一种定义。品级配色、徽记、卡框与演出预设放入一个小型 CardPresentation 配置（每品级一行，主题副色为列表），不为边框、光效、音效分别建表。

有多个抽取池后再定义 DraftPool：池内条目/权重使用嵌套列表，设置 drawCount、稀有度权重、前置条件和保底策略。稀有度权重与池内同级卡权重分开，不能同时不加说明地叠乘两套概率。候选先过滤已满层/未解锁/无效效果，再按版本化 PRNG 无放回抽取，同屏不重复；不足候选时使用明确兜底，不为凑数悄悄换牌。

首版不强制每次出现高品质卡。概率、保底、重抽次数和构筑平衡需通过实测确定；保底状态和抽取版本属于局内状态，不能在打开/关闭窗口时重新掷骰。需要服务器复演时记录池版本、seed、候选集与选择命令，演出随机数不得消耗领域 PRNG。

## 选卡时的时间规则

当前是清波后进入 ChoosingCard，领域 Step 只在 Fighting 且未暂停时推进。因此选卡期间不刷怪、不攻击、不计战斗 tick；选择后回到 Planning，由玩家开始下一波。无需把全局 Time.timeScale 设为 0，UI 打字/高亮/演出可以继续使用展示时钟。选卡也不会累计真实经过时间后突然补算。

之后即使改为战斗中升级选卡，当前单人方案仍建议暂停领域。合作/竞争模式另行定义全房间同步暂停或限时选择，不能把单机暂停直接移植到多人。

## 高品质演出草案

1. 候选由领域一次性确定，先完成三张必要资源加载，再播放呈现；资源失败使用静态卡面，不重新抽牌。
2. 普通/优秀使用轻量出现，稀有可有短边框流光；史诗/传说使用更鲜明的徽记、短促音效和少量特效。传说可规划从镜头外飞入/展开，约 0.6–1.0 秒，避免每次都打断阅读。
3. 整体卡片进入阅读状态后开放点击；尚未展示完的卡不抢先消费点击。选择成功立刻锁定，使用同一候选版本防重入。
4. 演出完成才揭示内容会增加等待，建议允许“跳过演出/减少动态”，直接展示同一组三张卡。不得因跳过而改变奖励或消耗次数。
5. 飞入 UI 使用独立卡片展示层/Canvas，不能移动真实战斗相机。模态输入挡住战场，兼容安全区、手机热区、后台恢复和关闭取消。
6. 粒子、材质、序列动画等通过 YooAsset 明确加载并在窗口销毁后归还；低画质减少粒子/后处理，避免全屏连续闪白和过长震屏。

未来验收重点：模拟 tick 不动而演出继续、连点只选择一次、重开/返回取消旧演出、后台回来不重抽、跳过与静态回退一致、三张不同稀有度可读、色觉辅助标记及目标手机性能。
