# Meshy 模型制作清单

当前项目只使用 Cube、简单几何体或图片占位，不制作正式 3D 模型。以下是供用户在 Meshy 制作与交付时使用的规格，接入时替换表现资源，不改变战斗或建设规则。

营地是大海岛中的局部区域。下表的帐篷、小屋与院落尺寸仅约束营地建筑，不代表全岛大小；地面、海岸与内陆延伸分开制作，保留通往其他区域的空间。当前不制作全岛小地图或探索系统，详见[世界尺度约定](IslandCamp.zh-CN.md#世界尺度与营地区域)。

风格：低多边形、轻度卡通、厚实轮廓；暖灰砂岩、木材、蓝旗/蓝瓦、铜金件、苔绿。参考本项目 imagegen 地图和图标，避免写实 PBR、细碎花纹与轮廓不清的暗部。

| 优先级 / 模型 | 尺寸与部件 | 动画/挂点 |
| --- | --- | --- |
| P0 箭塔 | 占地约 1×1，塔体高 1.2–1.6；石基/木弩/蓝旗 | 底座与炮台分离，TurretPivot；Muzzle；待机/发射 |
| P0 法塔 | 相近占地，晶体总高约 1.8；石身/铜环/青色晶体 | Crystal/Muzzle 挂点，待机轻动/施法 |
| P0 速射炮塔 | 相近占地，炮身可转向；石台/黑铁炮管/铜件 | YawPivot、PitchPivot、Muzzle；发射后坐 |
| P0 基地 | 占地约 2.2×2.2，总高 2.5；蓝顶小型要塞，明显入口 | BaseHit、旗帜；受击/破坏分件 |
| P0 普通/快速敌人 | 身高 0.65–1.0，体积半径约 .20–.30；可共用骨架 | Idle/Walk/Run/Attack/Hit/Death；Root、Head、HitPoint |
| P0 重装/精英 | 身高 1.0–1.4，体积半径约 .35–.45；轮廓明显更宽 | 同一动作规范，可共用骨架与材质变体 |
| P1 护卫/NPC | 身高约 1.0，蓝绿阵营；明确武器与朝向 | 待机/行走/攻击/受击/死亡；Weapon/Target 挂点 |
| P1 投射物/装饰 | 箭、炮弹、法球，以及可排序的树/石/旗 | 箭尖前向 +Z；与尾迹/命中特效分开 |
| P0 营地帐篷/小屋 | 帐篷约 2.4×2.0、高 1.3；小屋相近占地、高 2.5；暖帆布/木材/青蓝屋顶 | 原点在地面中心，入口朝 -Z；帐篷与小屋作为同一建设点的替换外观 |
| P0 围栏/院落套件 | 围栏约 6.2×4.4 的围合范围，前方留入口；铺装、水井、花圃、箱子和营火分件 | 地面吸附、共享材质；不在一件网格里烘焙所有阶段，方便逐级显隐 |

统一 Y 向上、+Z 为面向、单位米、缩放 1；原点在脚底/地面中心，禁止居中悬空。塔的根轴固定，炮台独立旋转；敌人不烘焙移动位移，使用 in-place 动画。导出 FBX（Unity 验收）并保留 GLB/源文件；材质和纹理独立提供，贴图 1K 为主、基地可 2K，尽量同材质共享图集。至少保留 BaseColor；法塔可有 Emission，不依赖在线 Shader。

建议第一档预算：普通塔 1k–3k 三角面、基地 3k–6k、普通敌人 .8k–2k、精英 2k–4k；这些是起始预算，最终由手机 Profiler 和目标同屏数量决定。提供简化 LOD/静态碰撞建议，不给每块砖添加独立碰撞体。逻辑体积写入 Enemy/Tower 配置，不能用模型 bounds 自动决定战斗射程。

接入交付按 models 标签由 YooAsset 加载 Prefab；动画、材质和纹理由 Prefab 依赖进入包。保持模型 ID 与战斗定义分离，同一逻辑塔可换外观。静态 2D 地图目前保留，树/桥/地面不必全部重新制作 3D；需要前后遮挡的装饰单独导出。
