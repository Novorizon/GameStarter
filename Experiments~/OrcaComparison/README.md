# ORCA 围攻对照实验

本分支从 `f67e8e6` 分离，在独立工作树进行实验，不修改 GameStarter 当前生产导航、UnityPackages、地图或现有验收门槛。

实际使用 [RVO2-CS 官方源码](https://github.com/snape/RVO2-CS/tree/de124a275d51d421bb9e2a77952210527ab60b04)，固定提交 `de124a275d51d421bb9e2a77952210527ab60b04`，保留 Apache-2.0 许可证、版权和上游源码格式，第三方 C# 文件未修改。原上游项目使用 .NET 10；实验项目直接把相同 C# 源编译至 .NET 8，未宣称 Unity/IL2CPP 兼容性已经验收。

## 不变的比较条件

使用原 `cross-junction-conservative-capacity-4m`：37×37、1m 逻辑格、原障碍、三个固定出生入口、半径 1m 的基地、72 个单位、实际单位半径 250mm、最大速度 1000mm/50ms。集结外扩距离仍为 4000mm，即最终身体中心到基地中心不超过 5000mm。没有扩图、改格、缩身体、缩人数或降低物理校验。

`witness.json` 来自独立构造的原场景可行性见证。加载时校验 IDs 恰为 1..72、原 seed=1 的固定出生映射、路径首尾及全部合法四邻边。目标仍为同一组 72 个合法格：12 个攻击位置、60 个候场位置。矩阵另外改变出生优先顺序和目标配对，避免只验证一种特别有利的配对。

最终候选每个单位都用新鲜 BFS 计算全局路径，不使用见证路径或见证串行入场次序。静态胶囊可见性简化减少中间格心引起的局部僵持；重新连接路径时，检查实际连续位置到下一路点的物理圆盘扫掠，不能直接连接时才回合法格心。包含解析墙角和偏心基地穿弦反例检查。

## 实际尝试

实验保留普通 BFS+ORCA、固定见证路线+ORCA、动态重路由、静态可见性简化、停车依赖及串行准入等变体。官方局部避让库本身不负责全局路线和围攻站位；普通逐格路点产生拥堵，单纯动态重路由也会卡住。

浮点边界的早期严格几何失败没有当作成功。最终保持实际物理半径 250mm，用 20mm 的额外 ORCA 避让裕量及 1.5m 出生净空；这增加约束，不缩小身体。出生请求在外部保留，成功结果必须 72 个请求全部实际生成并抵达。每个 50ms 逻辑步使用十个 5ms 子步，原速度上限保持不变。

静态简化+重路由在目标随机重配后仍出现 70/72 停滞。最终候选增加显式让位：停滞单位请求临近停靠者实际移动到可走的外侧临时位置，通行完成后恢复原目标。让位由 ORCA 执行，没有传送、忽略碰撞或改变最终目标集合。临时让位绝不计为到达；到达要求距原目标≤5mm，并通过真实攻击/集结范围。所有单位到位后继续保持 200 个逻辑步。

## 复现和证据

需要 .NET 8，无额外 NuGet 依赖。在仓库根目录：

```bash
python3 Experiments~/OrcaComparison/run_matrix.py
```

执行 4 种出生顺序×5 种目标配对，共 20 组严格全量到达检查，再单独执行基础方案和串行方案对照。基础方案失败单独报告，不与候选成功数混算。完整日志和原始 JSON 输出在 `Artifacts/OrcaComparisonMatrix`。

独立几何 oracle 源来自现有导航验收，用 double 坐标保留浮点位置，未放宽身体/障碍/基地的连续扫掠判定。每个 5ms 子步均检查连续身体、静态障碍、基地和实际速度；成功必须 72 个实际单位在原目标附近稳定 200 步。`MinimumSampledPhysicalGapMm` 仅为逻辑步末采样最小值，不能冒称连续最小间隙。`Ticks` 是从 0 开始的循环索引，实际已执行逻辑步数为 `Ticks+1`。

冻结结果及逐文件源码指纹见 `Evidence/matrix-summary.json`。逐组完整报告以 `.json.gz` 保存，可用 Python `gzip.decompress` 解压。汇总同时保留队列/到达数、让位请求/完成/超时、目标误差及原始报告 SHA-256。

## 适用范围

这是可运行的替代原型与严格对照，不是生产系统替换完成。尚未验证其他地图、混合体型/射程、死亡补位、多场战斗同时存在、Unity、IL2CPP 或移动设备性能。官方库当前暴露 `Simulator.Instance` 且没有删除 Agent API；生产接入需要独立 battle 实例和完整生命周期方案。外围让位/重路由是本项目实验代码，不宣称某商业游戏使用了同一实现，也不继承 ORCA 论文对不同模型的保证。
