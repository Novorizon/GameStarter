# r6/r7 执行层缺陷诊断

r6 的 open48 完整开发测试为 37 已到位、11 Moving。独立审计识别两项本项目缺陷，不能归结为商业游戏架构失败：

- 28 的 flowExit 与最终目标直线合法，但格心纠偏会在偏离格心后将其强制拉回；原 trace 末尾连续十步准确保留。r7 让经过实际身体半径扫掠验证的 flowExit LOS 优先。
- 3 的四邻格心组件无路，但实际当前位置到原 Goal427 的完整连续线对其余47身体与基地最小净空为14.288mm。零流方向不能等同于物理无路，后续增加经过圆盘扫掠验证的最终目标LOS兜底。6 的同类起点不能直接走目标，未套用该结论。

r7 开发 open48 在修复第二项前主动中止；文件标明最后完整微步，不能当作完成的失败或通过结果。后续正式共同矩阵仍须完整运行和重新重放。
