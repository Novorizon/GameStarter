# D：依据《帝国时代 IV》公开架构实现的导航候选

本候选是独立 C# 实验，基线为 GameStarter `8c0dd50`。它不包含或声称恢复微软/Relic 的商业源码。

## 核实到的一手来源

- Frank Cheng（World's Edge），GDC 2022：[演讲页面](https://gdcvault.com/play/1028036/Pathing-in-Age-of-Empires)。
- [GDC 官方完整幻灯片](https://media.gdcvault.com/GDC+2022/Speaker+Slides/Pathing+In+Age_Cheng_Frank+2022-03-29+00.16.38.pdf)，本轮已实际下载并阅读，共36个PDF页。PDF页码与幻灯片编号一致到35，最后另有致谢/活动信息。

公开资料确证：地形按块抽象出连接入口，块间搜索决定流场覆盖；方向由代价积分生成，LOS区域与FMM结合；为避免单块边界质量下降，可用重叠分段计算和缓存；混合通行限制从较受限类型扩展；局部控制同时考虑移动单位、不动单位和静态小障碍。幻灯片还介绍了编队与水陆接驳，后两者不在本轮统一地面塔防模型中。

## 本候选的具体选择

下面的参数与业务策略由本项目实现，不声称是商业游戏内部值：

- 8×8逻辑格为一个块；每个边界可通行格为入口节点，块内连接代价用四邻格最短路计算。
- 先在入口图做A*，随后在三块重叠片段中计算LOS/FMM距离及方向，按需推进；缓存按世界修订、身体半径、出口和片段覆盖区分。
- 混合体型允许以最大注册半径的合法距离值作为种子，再扩展到较小半径可走的区域。目标/片段对大体型不可达时独立计算，不捏造共享。
- 局部控制采用候选方向采样与邻居预测，连续圆盘运动由明确的物理停止规则约束；停止/冲突提案单独计数，不能靠碰撞夹紧被动宣称已到达。
- 最终驻留格、射程、排队、死亡补位和可选的显式让路属于塔防适配，不是GDC披露的攻击调度算法。基础与增强版本分别报告。

实现不调用 A 的 SIPP 或 B 的 ORCA。具体参数、功能覆盖及失败反例由统一 NavigationLab Runner 的冻结报告说明；有限测试不构成一般完备性保证。

## 复现层与原版细节的边界

官方PDF的SHA-256为 `bd2283202abc643abd7ba6e093a78fc07e89032f171cc34e8581330b7ac1512b`。未将整份受版权保护的幻灯片收入仓库。

| 披露的架构部分 | 本候选实际执行的位置 | 本项目的具体决策 |
| --- | --- | --- |
| 分块、入口图及HPA* | `HierarchicalFlow.Graph/FindRoute` | 8×8块，枚举合法边界格，块内精确四邻代价；按块内连通分量定位实际位置 |
| LOS与FMM积分 | `HierarchicalFlow.Integrate/Eikonal` | 解析圆盘扫掠判LOS，不实现原图示的影线扫描加速；双精度上风解，不复刻8位方向存储 |
| 重叠分段流与缓存 | `HierarchicalFlow.Direction` | 三块窗口及相邻叶块扩展；按出口、覆盖与半径复用，世界修改时整体失效 |
| 从受限体型扩展 | `HierarchicalFlow.Integrate` | 同片段内复用最大注册半径的可达种子，再向小体型区域积分 |
| 静/动/不动对象的局部控制 | `AoeNavigator/Steering` | 角度采样、预测、局部轮转提案；精确窄路点与连续扫掠停止，不宣称是原版公式 |

统一Core使用二值地面，本候选没有原版的加权地形/水陆接驳、完整编队虚拟领队或网络锁步工程。`MultipleTargets/DynamicTerrain/MovingTarget` 等插件能力表示本适配器实现了对应API，实际是否通过须看共同矩阵，不能仅依据标记认定正确。

## 保留的开发失败

`Evidence/Rejected` 保存实际执行过的失败输入/输出与源码历史。它们是开发诊断，不冒充最终冻结矩阵：

- 首次Forest12只生成2人：近邻预测错误地惩罚了安全远离动作；另一处路径定位把重复tile当成同一个可通分量。
- 窄路控制尝试曾在Forest44只生成7人；后续修正零长度提案竞争、已过路点回追及同帧提案相互假设，单Big及12Big才实际走通。
- r5仍有密集目标区反例：open48全出生但29人未到位，Forest44全出生但24人未到位。D1临时让路在同Forest44更差。当前独立审计在区分本项目路点/围攻控制缺陷，不将这些失败归结为《帝国时代IV》原版HPA/FMM的能力边界。

基础D0与D1额外让路分开保存。`YieldReturns` 在该开发版本是返程命令数量，不是已完成返场人数；最终到位只能由5ms独立oracle及稳定观察认定。

## 执行层修正与正式验证

r6 将精确不动身体圆盘加入私有HPA/FMM规划几何，并按身体集合变化失效缓存；它不修改输入地形或身体半径。r7 修正已验证flowExit LOS合法时格心纠偏导致的两步振荡。r8 在流方向为零、但实际位置到原最终目标的整段圆盘LOS合法时提供直达兜底。这是本项目对格心离散漏路的处理，仍受原5ms连续身体碰撞规则约束，不表示原商业游戏具有相同实现。

正式验证只使用共同冻结的NavigationLab v2输入与Oracle；开发途中中止的诊断不计PASS/FAIL。最终完整矩阵、fresh replay、所用源码与DLL哈希由本分支证据报告给出。
