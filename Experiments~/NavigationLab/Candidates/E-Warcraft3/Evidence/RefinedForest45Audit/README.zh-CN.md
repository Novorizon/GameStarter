# E4 Forest45：三个移动者的单体几何查询

原E4-v2完整Forest45运行到tick12000失败：45个身体全部实际生成，12攻击、30候场、3移动。这里仅从失败末态独立查询单个身体能否移动，不重跑矩阵，也没有改变候选、地图、身体、Goal或速度。

所有查询均**固定其余44个实际身体**，包括另外两个Moving单位。不是只固定42个已驻留者后将另外两个身体删除；后者不能作为原单体运动的安全见证。

| 查询 | 结果 | 可得出的结论 |
| --- | --- | --- |
| id14，原Goal304 | Goal中心距id15仅100mm，两体半径和400mm | 15保持当前位置时，14不能抵达自己的Goal；需要15先离开或联合变化 |
| id15，原Goal259 | 25mm独立格点搜索扩展7点后未找到路径 | 未找到固定其他44体时的单体路；不是任意连续路线不存在的证明 |
| id19，原Goal213 | 25mm独立格点搜索扩展6209点后未找到路径，未耗尽30000预算 | 同上；不将有限格点搜索当连续空间无解定理 |

初步曾怀疑id15恰夹在两个相切圆之间，四分格轴不含当前X，可能沿精确竖直方向逃离。实际地图核对否定了所设两段路径：`(9150,-4310) → (9150,-4810) → (8750,-4810)` 两段都穿过原阻挡格矩形 `(9000,-5060)—(9500,-4560)`。这条假设没有成为合法见证，也没有据此修改算法或放宽几何条件。

目前这些查询**没有确证新的E4连接漏路**，也不能推出“必须移动42个已驻留者”；三个Moving之间可能存在先后或协同运动。没有找到路线的结果按原范围保留，不能推广成物理不可能、商业Warcraft III算法限制，或当前E4在所有地图普适。

## 复现

```bash
python3 query.py
python3 query.py --actor15
```

第一条重现被否定的id15两段假设、id14的Goal占据以及id19的25mm查询；第二条单独重现id15的25mm查询。`geometry.py`为独立解析线段—圆/矩形检查，沿用此前只读几何查询实现，没有调用候选E或给其输入见证路线。所有原体型为r200、速度100mm/50ms、射程450mm。

`query-result.json` 和 `id15-fine-result.json` 保存真实结果，原完整输入及失败报告保留。`manifest.json`记录本次封存指纹；这不是候选的新通过报告或成功Oracle重放。
